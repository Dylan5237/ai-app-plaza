# AI 应用广场 UI/UX 规范

版本：v0.3 · 2026-11-11 · 二阶段统一实现依据，产品验收另行核对

交互规范入口：`/?iteration=2&design=system`。产品原型入口：`/?iteration=2`。

本规范覆盖二阶段原型的发现、详情、分享与审核、个人空间、权限与本地小组、Agent 接入及管理状态。它定义预期交互，不把原型中的示例身份、自动准备、推荐或执行结果视为后端能力已实现。

## 1. 产品方向

广场面向发现、使用和分享。采用暖白画布、钴蓝行动色、杏色分享入口以及按用途区分的应用标识；用内容、作者与真实更新吸引探索。管理页面保持清晰、克制。参考伏羲规范的“规则与可操作示例结合”方式，不照搬其管理工具视觉。

页面减少重复导航、重复确认与不必要填写。可靠信息自动准备，必要缺口才询问。涉及权限、本地环境或破坏性变化时直接呈现影响，保留一次明确确认。

## 2. 视觉变量

正式页面共用 `src/styles/design-tokens.css`；审阅原型在独立工作树中使用相同变量。规范约束二阶段每一段的实现与审查，后续页面优先复用共同组件，不各自定义另一套视觉、状态或动效。

| 用途 | 值 | 使用规则 |
| --- | --- | --- |
| 画布 / 表面 | `#F8F7F4` / `#FFFFFF` | 应用内容置于白色表面；画布保持微暖但偏白 |
| 标题 / 正文 / 辅助 | `#202A3B` / `#596477` / `#657085` | 普通文字对比至少 4.5:1 |
| 品牌 | `#3E58CE` | 主要操作、焦点与选中 |
| 分享 | `#FFC89B` + `#613215` | 杏色底配深棕文字 |
| 成功 / 警示 / 错误 | `#267154` / `#925A16` / `#B83F4B` | 同时给出文字或图标，不只依赖颜色 |
| 圆角 | 卡片 16px / 控件 9px | 不为每页新增一套 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px | 页面 28–32px，小屏 16px |
| 字体 | Segoe UI / Microsoft YaHei / sans-serif | 不请求外部字体 |
| 字级 | 页面 27/36、分区 15/24、正文 13/20、辅助 12/18 | 11px 限非关键元数据 |
| 图标 | Lucide 20px / 描边 1.7px | 装饰隐藏于读屏，操作具有文字名称 |

## 3. 布局与导航

- 桌面端使用 252px 固定左侧栏，按“浏览 / 我的 / 管理中心”分组；全部应用、随便看看、智能查找、我的收藏、我的应用、应用交接与管理入口直接到达。智能查找为广场默认首页（`/`），全部应用与随便看看分别对应 `?discover=catalog`、`?discover=random`。品牌区可回到首页。右侧内容独立滚动，侧栏在窄屏转为顶部局部导航。
- 模块：应用广场、管理中心、Agent 接入；侧栏直接到目的地。搜索、类型、排序和任务标签属于页内筛选，不再增加重复页签。
- 发现页：页头为主标题、数量、说明与杏色分享入口；下方为紧凑工具栏、任务标签、应用网格、分页。1440×1000 下第一行卡片顶部不超过 300px。
- 网格：默认 3 列；1780px 起 4 列；1120px 以下 2 列；650px 以下 1 列。小屏侧栏转为局部横向目的导航，页面本身不横向溢出。
- 滚动区域统一使用细滚动条：透明轨道、低对比圆角滑块，悬停加深；Element Plus 内部滚动条保持一致，不出现系统粗滚动条。
- 智能查找：对话占满主内容区，消息独立滚动、输入框固定在底部。适用应用与理由嵌入对应回答，沿用统一卡片；后续提问保留前文推荐，详情返回恢复会话位置。
- 管理页：页头、筛选、表格、分页。只在选中时显示批量操作。排序和筛选先于分页；条件变化回到第 1 页。
- 详情独立展示，返回恢复目录查询、标签、类型、排序、分页和滚动位置；轮盘还原批次及当前位置。无来源的详情直链回到目录。

## 4. 统一应用卡片

正式页面复用 `src/components/CatalogCard.vue`，图标复用 `PlazaIcon.vue`。目录、轮盘、推荐只改变排列。

信息顺序：名称与行内版本 → 简介 → 能力类别与标签 → 作者、创建/更新日期。标题单行截断，摘要两行截断；收藏使用书签图标置于右上角。本次更新不单独占用行，版本号以名称后的竖线分隔小字呈现。

- 作者 `primaryEntry` 决定主操作。Web 为“打开平台”，Agent 为“接入我的Agent”。不可用入口不渲染可点击操作，在原位显示原因并保留可读作者信息，详情仍可用，不自动选择次入口。
- 卡片悬停时轻抬 2px、加深阴影；键盘聚焦显示品牌轮廓。日期淡出，右下原位淡入主操作文字（带箭头），不使用整卡蒙版。无法悬停的触屏设备隐藏日期并持续显示主操作。
- 收藏与标签独立可用；悬停这些控件不遮挡内容。选中文字不进入详情。收藏提供 `aria-pressed`。
- 键盘可见焦点显示主操作；完全无法悬停的触屏设备持续显示主操作，触达区至少 44px；存在可悬停输入（含鼠标触屏混合设备）时仍按悬停显隐。整卡点击和键盘聚焦标题进入详情；选中文字后仍可用键盘明确打开详情，主操作在可见前不接收指针点击。
- `prefers-reduced-motion` 下关闭过渡与位移，功能保持可用。

## 5. 控件、表单与确认

基础控件复用 Element Plus。一个任务只保留一个主要提交动作，分享入口用杏色。等待时禁止重复提交；禁用原因不能仅依赖悬停。

字段标签常驻，输入错误靠近字段并可读。可靠读取的资料预填；不确定内容不能标成已验证。自动保存使用轻量状态，避免连续消息。

弹窗完成一个短任务，宽 480–720px，小屏不超 92vw。抽屉承载补充上下文，不承载多层导航。关闭后恢复触发点，模态内焦点受约束。不要叠加模态。

分享、授权、删除和职责交接直接随选择展示影响；没有单独“预览影响”步骤。确认包含对象、影响及可恢复性；无变化不可重复提交。

## 6. 状态与内容

| 状态 | 表现与恢复 |
| --- | --- |
| 初次加载 | 骨架及当前阶段；无真实进度不显示百分比 |
| 刷新中 | 保留旧内容，显示更新状态 |
| 空目录 | 解释没有内容，提供分享或准备入口 |
| 无匹配 | 保留条件，提供清除或调整筛选 |
| 请求失败 | 保留现场与重试入口；不显示为零数据 |
| 结果未知 | 核对原操作，不重复提交 |
| 部分完成 | 保留成功项，只处理待完成项 |
| 权限失效 | 重新核验；失权收藏用通用占位，不泄露原名称 |

使用“动作 + 对象”表达结果；关键错误与恢复入口持续可见。日期标准为 YYYY-MM-DD，事件加 HH:mm 及必要时区。热度表示使用意向，不表示成功率；统计标明时间、口径和授权范围。作者声明、示例产物和真实验证分开表述。

## 7. 二阶段任务路径

| 任务 | 最短路径 | 自动处理与边界 |
| --- | --- | --- |
| 浏览与使用 | 浏览 / 搜索 → 查看条件或主入口 → 使用 | 匿名浏览；当前权限过滤后排序分页，网页显式最近更新 |
| 随便看看 | 一批应用 → 切换 → 换批或使用 | 卡片区域支持滚轮、方向键与触屏切换；滚轮输入连续跟随，停止后自动居中；限制未完成的滚动距离，避免松手后连续补跳。首尾卡片从边缘淡入淡出，不横穿前景，不重新抽样。可见上架全集等权最多 6 项，批内不重复；换批避开上一批，失败保留；“全部”只指当前批覆盖全集。换一批与切换控件同排，紧贴卡片热区；轮盘舞台在页内垂直居中，不在底部留大片空白 |
| 智能查找 | 任务 → 必要澄清 → 匹配依据 | 不要求先填多项参数；失败明确降级，不补造推荐。智能服务未接入期间明确标注“基础检索：按关键词匹配，不代表对任务的理解”；无匹配如实告知并给出调整或回目录出口；等待可取消，未提交的新草稿标注上一轮结果；切换页签或查看详情后返回保留会话 |
| 分享与更新 | 来源材料 → 必要缺口 → 提交审核 | 自动整理、草稿保存；首次和更新均审核，审核中保留旧公开版 |
| Agent 接入 | 选择应用 → 确认影响 → 结果 | 自动核验可知状态；同版不重装，高版不降级，本地改动先保护；未知不假定成功 |
| 权限与职责 | 修改 → 即时影响 → 确认 | 身份复用天宫、小组本地管理；服务端核权；交接等待接收人接受 |

能力目录、审核路径和角色范围仍以二阶段已确认需求与权限矩阵为准。本规范不新增业务权限或生产授权。

## 9. 核对方式

交互规范包含按钮、筛选、表单错误、入口停用、收藏、详情、影响确认及七类反馈状态。它复用真实组件，但演示数据独立于产品原型，不写入原型收藏或应用状态。

真实实现的开发验证应覆盖悬停/聚焦主操作显隐、快速经过、触屏、文本选择、返回现场、禁用入口、各类失败、移动无页面溢出，以及既有真实业务回归；本轮不继续测试交互原型。人工浏览与实际业务验收分别进行；测试通过不代表用户认可视觉与交互。

## 10. 分阶段落地边界（2026-11-06）

用户确认先实施第 0、1 段。第 0 段核对基线与本轮修订，第 1 段按 #95 完成公开目录发现与使用，并采用当前已核对的视觉与交互。公开导航当前仅显示全部应用、随便看看和既有管理入口；不呈现尚未接通的收藏、热度、智能查找或用户身份。更新说明随后端版本资料能力交付，不把空白数据伪装为已采集的 0。

第 2 段身份、分享与个人空间，第 3 段提交审核与资产维护，第 4 段热度和运营汇总，第 5 段智能查找，第 6 段 MCP 与本地接入更新，均遵循本规范。验收检查共享变量与控件、导航层级、信息密度、键盘/触屏、状态反馈、返回现场及动效；业务未实现不以模拟结果替代。

本轮最新修订优先于旧稿：身份复用天宫，小组由广场本地管理；导航改为模块加直接目的入口；智能查找占满主内容区并在回答中呈现应用；卡片悬停主操作与轮盘采用本规范当前参数。后三项按对应实施段接入真实能力。原始完整二阶段需求仍保留于需求候选工作树，不在首段引入身份或审核改造。

2026-11-09 用户体系先行：显式启用真实身份服务后才显示天宫身份、我的收藏和获授权的成员与小组入口。收藏在统一卡片和详情中独立操作，不触发主操作；保存成功才选中，失效收藏显示通用占位。个人区详情返回恢复原位置。小组表单随选择展示成员变更及影响，只保留一次“确认保存小组”，无变化时禁用。应用归属、受限分享及审核随对应后端能力继续接入。

2026-11-11 桌面视觉重构：统一为左侧分组导航与独立滚动内容区；品牌区回到首页，随便看看轮盘只保留卡片与轻量切换控件，不再在卡片下方堆叠操作按钮；卡片改为名称/行内版本、简介、类别与标签、作者/日期的紧凑结构，收藏使用书签；画布微调为 `#F8F7F4`，滚动条统一细化。应用管理、运营看板、成员与小组沿用同一左侧栏与表面层级。

2026-11-12 卡片对齐参考原型：目录与个人收藏卡片改为内容紧凑高度（桌面 200px、矮屏 170px），悬停轻抬卡片，悬停/聚焦以右下文字主操作替换日期，取消整卡蒙版；类别标签恢复浅色胶囊。轮盘保留现有舞台高度，卡片交互随统一组件生效。

2026-11-12 用户试用反馈修订：随便看看舞台垂直居中，换一批移入卡片下方切换控件同排，空目录与失败时仍可换批；分享弹窗托管链接改为“查看 GitLab 仓库（统一托管空间）”；运营看板内容区独立滚动，底部面板与脚注不再被截断；“应用归属核验”改为“应用负责人”，管理员选人后直接指定，不再填写核验依据或勾选授权核对，角色调整同步取消原因必填，审计仍记录操作人、前后值与请求标识；“负责人交接”入口改名“应用交接”，页内说明其接受、拒绝与取消用途。

2026-11-13 智能查找基础版：智能查找成为广场默认首页（`/`），侧栏浏览组新增“智能查找”入口，全部应用与随便看看改为显式 `?discover=catalog` / `?discover=random` 链接；发布确认（含 hash 返回与“刷新目录并查看应用”）仍回到全部应用。智能服务未接入期间为明确标注的基础检索：按任务文本关键词召回可见上架应用并按命中数排序，结果区常驻“基础检索”标注；“为什么出现”说明命中词，无有效关键词或无匹配时如实告知，不补造推荐；会话式界面支持新对话、修改需求、等待取消、未提交草稿标注上一轮结果，页签切换与详情往返保留会话及阅读位置。后续接入智能服务时替换召回与理由生成，不改此交互骨架。
