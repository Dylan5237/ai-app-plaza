# 当前原型能力边界

适用范围：本文仅说明 `?prototype=1` 的历史 Mock 原型，以下“未接入”不描述当前真实门户。现行产品见[主流程范围](mainflow-scope.md)，Agent 上传、分享和更新见[统一接入规范](../integration/publishing.md)。

本文说明 AI 应用广场当前交互验证原型实际覆盖的能力。原型共展示 17 项完整 Mock 应用资料和入口，其中 6 项为平台工作台演示、11 项为 Agent 接入提示词；示例资料、版本、日期和状态均不代表真实项目发布或验收情况。

## 面向的使用场景

- **使用应用**：按工作目标浏览和查询应用，使用标签筛选、收藏，并查看详情中的适用场景、准备材料、预期产出、使用步骤及边界。查询依据本地关键词和登记信息匹配，不是 AI 语义检索；收藏状态保存在当前浏览器。
- **分享我的 AI 应用**：体验从整理发布资料、查看预览到确认发布结果的示例流程。它用于展示发布协作方式，不会真实发布应用。

## 打开平台与接入 Agent

- 6 项平台应用的“打开平台”入口进入同源的独立示例工作台，可查看各自的任务处理预览、结果和示例报告。它们是 Mock 场景，不代表对应平台服务已经部署或可用。
- 11 项 Agent 应用提供完整的接入提示词，供使用者复制到自己的 Agent。提示词中的 `example.invalid` 地址仅作演示，不能用于访问、下载或安装。广场不会代替使用者运行 Agent、安装应用或处理凭据。

## 发布提示词、预览与反馈

分享流程提供只读的发布提示词、示例发布草稿和只读预览。作者可复制带有当前草稿上下文的修改或修复提示词，在自己的 Agent 对话中补充自然语言要求，再回到示例流程查看预览。原型也展示一次模拟的收录失败及重试过程；源码上传、版本发布、广场收录及其结果都只是浏览器中的演示状态。提示词复制和示例状态不表示 Agent 已连接或发布已执行。

## 当前未接入

当前没有后端服务、GitLab 集成、真实应用安装、真实 Agent 调用或 AI 语义检索。门户不上传源码、不校验真实仓库权限、不接收外部 Agent 的草稿回传，也不以 Mock 入口或状态证明真实服务能力。
