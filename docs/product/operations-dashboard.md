# 运营看板口径与接入

看板只面向经服务端逐次重新核验的广场管理员和超级管理员。仅拥有小组、名册管理或应用维护权限不代表可查看看板。接入方负责登录状态、失权处理与导航；不会通过浏览器传入的角色或来源判断权限。

`registerOperationsDashboard(app, db, options)` 注册 `GET /api/operations/dashboard?period=7d|30d|90d`。`options.authenticateAdministrator(request)` 必须重新核验身份及管理员角色，失败时抛错；路由先执行该检查。`options.visibleAppIds()` 由服务端权限模块返回当前公开且上架的全部应用 ID。不能把当前登录者可见的私人或小组应用加入；未提供回调时应用相关指标不可用，不默认全量。`options.analytics` 使用服务端配置的环境和站点，不能由请求指定。接入方还需要为该路径附加门户凭据及失权响应处理，并确保页面仅对管理员可进入。

结果不返回访客 ID、会话 ID、搜索原文、凭据、受限应用或逐人行为。范围以查询时公开上架状态为准；历史表现随着应用当前公开范围变化。浏览器事件均可能漏采，数据是已观测记录，不代表精确人数或所有实际操作。来源和流量类型当前均未知，不能解释为真实人数或自发流量。

## 指标

- 时间区间为查询时刻向前 7/30/90 个 24 小时的左闭右开区间，展示北京时间。只从采集基线开始；基线晚于所选区间起点时明确显示部分区间。未启用采集、无基线和未接通公开范围分别提示，不将不可计算显示为零。
- 公开应用发现会话：通过卡片/搜索结果/直链查看公开应用详情、Web 入口点击或成功复制使用提示词的去重会话。使用意向会话：Web 入口点击或成功复制使用提示词的去重会话。同一会话多种使用行为只计一次。排除管理和发布后自查；跨日图表各日分别去重，不能相加得到区间会话数。该指标不含搜索、筛选，不能称为完整发现活跃会话。
- 匿名浏览器档案数只包含带持久匿名标识的档案；临时会话不计入档案。当前目录结果事件没有可信的公开/受限范围标记，搜索次数和零结果率无法安全拆分，暂不计算，避免混入受限应用活动。
- 使用意向动作数仅统计服务端 `heat_counted=true` 的 Web 点击和成功复制使用提示词；同一访问端、应用及行为 30 分钟内去重。它不表示目标平台打开成功或 Agent 安装成功。
- 应用表只返回当前公开上架且在所选区间有已记录事件的应用，按卡片曝光降序最多 50 条；分别列曝光次数、详情会话、Web 点击会话与成功复制会话。曝光与会话不能直接作漏斗转化，直链及直接使用可能没有曝光。
- 当前在架数读取当前公开上架快照。首次收录和版本更新使用已记录的服务端收录事实，按应用去重；基线存量不是新增，资料编辑和无变更收录不算版本更新。统计链路故障时事实可能缺失，不能据此推断未发生。
- 第 2 周留存与 28 天重复发现依赖包含搜索和筛选的完整首次发现记录。由于目录结果事件无法按公开范围筛选，当前不可计算；未来还需有可靠的首次观测锚点和完整观察期，不能将过期明细后的首次出现误认为历史首次。观察的是再次发现，不等同应用内留存或自然人留存。
- 48 小时发布漏斗尚未接通可靠的成熟批次关联，页面明确显示不可计算，不推断步骤完成或流失。

## 验证边界

专用测试覆盖采集基线、环境站点隔离、公开范围、管理员鉴权、去重动作和不可计算状态；浏览器夹具用于检查页面交互和失权状态，并非真实门户身份或生产数据验收。页面、权限回调及路由必须在集成候选中联合验证，技术检查通过不代表业务验收。
