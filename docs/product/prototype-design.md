## 工程信息

- Profile：`vue3-element-plus`；运行时：Vue 3 + Element Plus（伏羲官方生成的 Vite 工程）。

## 页面与交互

首次进入展示需求输入框与常见任务示例。用户描述工作目标或预期产出后，在同一页面查看匹配能力；不设置按交付形态分类的导航，也不区分“任务导航”和“发现工具”两个入口。

列表固定每行 4 张卡片、每页 8 项，满页两行。卡片参照伏羲平台的项目卡片层次：项目名称、右上角版本、两行简介、作者标签、分隔线、作者与收藏，以及两行创建时间和更新时间。以“名称 + 用途”识别应用，例如 AuroraFlow 需求工作台。演示入口、准备条件、项目资料与使用边界保留在详情中。

通用项目字段包含 `id`、`name`、`summary`、`owner`、`tags`、`version`、`createdAt`、`updatedAt` 和使用入口。版本表示项目当前发布版本；创建和更新时间属于项目本身，不以门户同步时间替代。正式接入时从项目登记元数据或仓库信息读取。原型中的版本与日期独立保存在 `pt-project-metadata` 示例数据块中，页面统一标注“示例数据”，不代表各项目真实发布信息。字段设计不受当前材料是否齐全限制。

日期区域与伏羲平台卡片一致：右对齐两行纯日期，创建日期使用 10px 字号和 0.82 透明度，更新日期使用 12px 字号，颜色为 `#a0aec0`，行高 1.25、行间距 1px。通过 `datetime` 和无障碍标签保留日期语义。

配色采用中性灰背景、白色卡片与单一蓝色强调。版本号使用低强调灰色徽标，默认标签使用浅灰底和细边框，选中标签才使用蓝色；日期保持伏羲卡片原样。标签超过 3 个时展示前 2 个和剩余数量，点击数量进入详情查看全部。支持点击卡片查看详情、点击标签筛选、收藏、重新描述需求、无匹配结果，以及“分享我的AI应用”与只读发布预览。

## 详情页

详情页按使用者的决策顺序组织：项目名称与一句话用途 → 适用场景、准备材料和预期产出 → 开始使用。取消原有三个详情页签，左侧集中展示场景、材料、产出及默认展开的使用步骤与说明，右侧只保留使用入口、主操作和咨询入口；版本、作者、自定义标签和创建/更新时间保留在页头。仓库标识、文档摘要、示例任务、最小验证方法和使用边界收纳到“项目资料与使用边界”。通过合并页头元信息与紧凑间距减少滚动；内容较长或展开项目资料时，只滚动左侧内容区域，不截断说明。

右侧主操作统一为两类，由登记的 `accessMode` 决定：`platform` 显示“打开平台”，进入当前页面同源的独立示例工作台；`agent` 显示“接入我的Agent”，打开完整接入提示词供用户一键复制到自己的 Agent。17 项应用均提供 Mock 演示入口，其中 6 项为平台工作台、11 项为 Agent 接入提示词。Agent 提示词中的 `example.invalid` 地址是演示来源，不能访问、下载或用于真实安装；Mock 入口和接入说明不代表目标应用已实际部署。使用咨询作为次要操作保留。

“使用步骤与说明”位于左侧，默认展开，仍可手动收起；准备建议与前置条件一并展示，并与当前演示入口同步。每项应用当前配置一个 Mock 入口。咨询可生成、编辑并复制包含当前需求的草稿，不发送消息。接入提示词使用现代剪贴板 API，并兼容普通 HTTP 页面的复制；复制不可用时选中完整文本供用户手动复制。

原型为 17 项应用提供完整 Mock 资料和演示入口。6 项平台应用分别进入同源独立示例工作台，每个工作台有 3 个不同场景的任务，可查看各自的处理预览、结果和示例报告。11 项 Agent 应用各提供一份完整接入提示词，内容包括仓库与文档来源、环境和依赖要求、示例任务、最小验证方法及使用边界；其中的 `example.invalid` 来源均为保留的演示域名，不能访问、下载或用于真实安装。Mock 内容用于通用产品交互设计，不表示真实项目已经提供相应能力、服务、部署或验收。门户只展示和复制提示词，不执行本机安装、远程部署或凭据操作。

项目及入口登记 `accessMode: platform|agent`；`entries` 支持 `label`、`url`、`onboardingPrompt`、`agentKind`、`steps`、`requirements`、`description` 和 `status`。当前 17 项各有一个 `demo: true` 入口：平台入口关联同源独立示例工作台，Agent 入口提供非空的完整 `onboardingPrompt`。提示词中的 `example.invalid` 地址仅用于说明接入流程，不能作为真实来源执行安装。`agentKind` 只服务于接入说明，不作为使用者的分类导航；`ready` 表示原型中的演示入口可交互，不代表真实服务、安装或连接已就绪。版本、日期和资料内容均为 Mock，不代表实际项目发布或验收情况。

## 分享我的AI应用

作者可通过“分享我的AI应用”体验从项目上下文生成发布资料的流程。整个页面始终显示“演示流程”标识；发布、修改和修复提示词均为只读文本，只能复制给作者自己的 Agent。原型不调用 Agent 或 GitLab 服务，也不会真实上传源码、发布版本或安装应用。

流程分为三步：

1. **交给 Agent**：复制只读发布提示词，交给有该项目上下文的 Agent。提示词要求 Agent 根据项目资料整理发布信息，不由作者在广场表单中手工填写。
2. **查看发布预览**：示例 Agent 草稿自动汇总应用名称、简介、作者、标签、适用场景、输入与输出，以及目标仓库、分支、版本、发布范围和上传文件摘要。所有信息只读，不提供可编辑字段。作者可复制包含当前草稿上下文的只读修改提示词，并在自己的 Agent 对话中补充自然语言调整要求；标签也由 Agent 根据作者的自然语言维护。草稿更新后需重新查看预览。
3. **确认演示并查看结果**：作者确认后，页面逐阶段展示源码上传、版本发布和广场收录三项发布结果。接入验证始终显示“待使用者接入 / 未执行实际安装”，不属于发布成功门槛。状态均为浏览器内的模拟结果，不代表真实仓库或服务状态。

演示包含一次收录失败恢复：先展示源码上传和版本发布已完成、广场收录失败；作者复制只读修复提示词交给自己的 Agent 后，示例只重试广场收录。前三项发布阶段成功后，目录新增 DocPilot 示例，可查看新应用示例；接入验证仍显示“待使用者接入 / 未执行实际安装”。该条目只存在于当前浏览器的演示状态，不会真实上传或登记。

正式发布需要接入 MCP 服务、作者身份与仓库权限校验，以及 Agent 草稿回传能力；演示中的提示词复制和阶段状态不构成这些能力已接入的证明。

使用者可从首页“按标签筛选”进入，或在能力搜索结果中叠加标签条件。多选标签按“同时包含”筛选，并与需求搜索结果取交集；卡片和详情中的标签可直接点击，支持取消单个条件和清空标签，清空时保留当前需求。标签选择器支持搜索和分页，避免全部标签长期占据页面。

目录保留 17 条原始研究记录，并补充用于交互设计的能力短名和检索词。完整展示资料由`prototype/portal-mock-content.json` 与 `scripts/portal_mock_data.py` 生成；原始研究 JSON 仍保留，生成过程不会将 Mock 内容回写为课题事实。17 项均有 Mock 详情与入口，其中 6 项平台对应独立工作台及各自的预览、结果和示例报告，11 项 Agent 应用对应完整接入提示词。Mock 资料还包含仓库标识、文档摘要、示例任务、验证方法和使用边界，不代表真实课题交付。查询使用本地分词、关键词与登记信息匹配；相关词用于解释结果，不代表语义理解或匹配准确率。当前未调用 AI 服务、GitLab 或其他外部 API。桌面版收藏与查询状态保存在当前浏览器；对话内预览使用宿主提供的状态存储。

运行时通过 Vue 页面承载同源 `public/portal.html`。Lucide 图标脚本随本地资源打包，运行时不依赖 CDN。页面和 iframe 均使用相对资源路径，`vite.config.js` 配置 `base: './'`。每页固定 8 项，卡片高度随可用高度在 190–226px 之间调整；极矮窗口仅当前内容区域滚动。仅维护桌面网页版，最小宽度为 900px。

## AdminSpec 与数据

初始 Vue 工程由 AdminSpec 编译器生成；当前交互页面使用 alignment 模式的自定义实现。17 条原始研究记录、用户文案与能力检索词作为独立数据块保留。`prototype/portal-mock-content.json` 保存用于详情展示的 Mock 资料，`scripts/portal_mock_data.py` 将其与原始记录合成为页面展示数据；不改写原始研究 JSON，也不把 Mock 内容视为真实课题交付、能力实现或验收证据。

## 构建与运行

需要 Node.js 20 或更高版本、Python 3.10 或更高版本（命令名 `python`）。在仓库根目录执行。

```powershell
npm ci
npm run build
npm run preview
```

部署/预览时使用 Vite 生成的 `dist/`，当前交付入口为 `dist/index.html`。Vue、Element Plus 与 Lucide 都由本地依赖构建或随静态资源复制；不需要运行时 CDN。
