# 应用归属、分享与平台管理

当前候选复用天宫核验身份和广场本地小组。新应用由确认该次发布的有效广场用户负责，默认仅自己；分享范围为全体成员（公开，允许未登录浏览）、指定成员、指定小组、仅自己。指定成员或小组按并集生效，小组按读取时的当前启用状态与成员关系判断。

负责人和明确授权的维护者可维护应用；分享收件人、小组成员、名册管理员不因此获得维护权。只有负责人可改分享、委派维护者或发起交接，维护者不能继续委派。交接须接收人接受，等待期间归属不变；接受时复核权限修订，保留版本和分享，原负责人不自动保留维护权。

平台管理员可看运营看板及必要治理清单；超级管理员还管理平台管理员和共同名册。平台治理身份不自动读取所有私有正文。指定的超级管理员账号由服务端配置，只有天宫成功核验后的精确账号可首次绑定，随后固定到稳定用户 ID；同名换身份拒绝自动重绑，不从昵称、客户端字段或首个登录者推定。普通管理员任命须超级管理员确认，最后一位超级管理员不能直接撤销。

存量应用没有归属记录时，沿用原公开范围；不按作者姓名或 GitLab 名称自动认领，不批量转私有。平台管理员逐项核对稳定应用 ID、来源授权和原公开授权后指定已核验负责人；后续通过交接变更。生产中的人员指派和迁移是独立操作，不由数据库建表或代码发布自动执行。

列表、计数、形态数量、标签和随机批次先按当前访问者过滤，再排序或分页。详情、资料、接入说明、包下载、收藏和管理使用同一授权数据；MCP 消费侧仍匿名，只能读取公开应用。关闭身份功能也不能使已经受限的应用变为公开。收藏失权时使用通用占位，页面清除旧身份数据。

权限变更使用修订检查和操作请求 ID，在同一事务保存变更及真实操作者；结果未知时回读或沿用原请求，不重新生成授权操作。版本、生命周期和分享是独立状态，分享变更不制造应用版本。

看板仅管理员访问，服务端逐次重新核验天宫会话与数据库角色。应用统计限定当前公开上架应用，不返回受限正文、名称或单项计数；没有可信公开范围标记的历史搜索和留存显示不可计算。

## 发布与客户端过渡

网页与 API 的管理入口在身份模式下按本人负责或明确获委派的应用过滤。旧应用须先核验归属，旧发布密钥或 GitLab 权限不能代替广场维护授权。首次上传尚未绑定网页身份时，通过原私有回执继续；没有全体可见的上传占位或私有预览列表。

来源上传仍沿用原 GitLab 授权或应用专属发布凭证，不把天宫 Token、Cookie 或浏览器会话交给 Agent。匿名提交与回执只返回必要状态及本人私有预览链接，不返回受限预览正文、差异、摘要或应用 ID。最终确认与重试必须由有效广场身份完成，并在实际登记事务中再次核对维护权限。更新确认前保留原版本，更新不改变原分享。

受限应用的更新说明由已登录维护页面提供固定版本和修订号。官方 CLI 可用 `--managed-app-id` 配合 `--expected-revision` 直接准备该修订的更新；仅正式更新接受这个参数，原请求恢复不能更改修订号或正文。服务器仍核对固定来源、发布凭证、乐观修订和版本递增；冲突时回到维护页面重新取得说明，不猜测 revision。旧 CLI 对公开应用沿用原行为；私有应用需要重新取得官方工具和维护页面说明。

受限应用的分发包由本人在已登录网页下载、核对摘要后交给 Agent；匿名 MCP 和下载地址不携带网页授权。页面在账号切换、角色变化、返回焦点及接口失权时清理或重新核对受保护内容，未确认响应不能覆盖新身份。
