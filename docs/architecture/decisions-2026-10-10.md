## 工程选择

- Vue 前端、单个 Node.js / TypeScript 模块化后端、PostgreSQL；HTTP/MCP 共用逻辑，不先拆 worker 或消息队列。
- ai-app.json + 指定 Markdown，由 Agent 维护；固定 commit 必需，tag / Release 可选，没有正式版本如实显示快照版本。
- 显式确认切换目录快照；普通提交和新 tag 不自动更新目录；定时对账辅助，不强制安装 Webhook。
- 中文任务检索按效果验证；作者标签多选 AND；不提前引入向量数据库。
- 使用申请复用目标系统的说明、外链或联系人；不建广场审批流。
- Codex、WorkBuddy 为首批兼容验证对象，实测前不声称已支持。

这些是落实已确认方向的工程选择，不增加业务功能。首个开发范围、接口、非目标和验收条件仍需形成具体合同。
